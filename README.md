## Requirements

- Python 3.13
- pandas
- numpy
- matplotlib
- scikit-learn

Install the required Python packages using:

```bash
python -m pip install -r requirements.txt
```

## Running Task 1

From the project root, run:

```bash
python task1/task1_retail_analysis1.py
```

The script performs retail data analysis, compares predictive models and generates visualisations.

## Running Task 2

From the project root, run:

```bash
python task2/task2_recommendations1.py
```

The script analyses customers, products and transactions, generates recommendations, compares algorithms and saves results.
